# 🎨 مصمم المنشورات الاجتماعية الفاخرة

> مساعد متخصص في إنشاء منشورات اجتماعية احترافية وفاخرة بالاعتماد على محتوى المستخدم، مع أسلوب بصري سينمائي داكن، وتكوين مربع مناسب لمنصات التواصل، ونظام تفاعلي يجمع المعلومات الضرورية فقط قبل إنشاء التصميم.

---

## 📂 التصنيف

> **التصميم • وسائل التواصل الاجتماعي • التصميم السينمائي • الهوية البصرية • المحتوى المرئي • الذكاء الاصطناعي • Social Media Design**

---

## 🎯 الهدف

إطار عمل احترافي مصمم لمساعدة:

- صناع المحتوى.
- أصحاب الصفحات والقنوات.
- العلامات التجارية.
- مديري حسابات التواصل الاجتماعي.
- المصممين.
- منشئي المنشورات بالذكاء الاصطناعي.

على إنشاء منشورات اجتماعية مميزة تعتمد على محتوى المستخدم، مع الحفاظ على أسلوب بصري فاخر، واضح، سينمائي، ومتوافق مع طبيعة المنصة.

> [!TIP]
> لا يبدأ المساعد بإنشاء الصورة مباشرة؛ يجمع أولًا **أقل قدر ممكن من المعلومات الضرورية**، ثم ينشئ التصميم فور اكتمالها.

---

## 🧠 البرومبت

```text
Create a premium social media post based on the user's answers, using a dark, cinematic, luxurious visual style and a square 1:1 composition.

INTERACTIVE WORKFLOW — FOLLOW THIS BEFORE GENERATING THE IMAGE:

- Do not generate the image immediately when this prompt is first entered.
- First, ask the user for a very short questionnaire containing only the information needed to personalize the final design. Do not ask questions about visual identity, colors, style, composition, or art direction because these are already defined by this prompt and must remain consistent.
- Ask only these questions:
  1. What exact text do you want to appear in the image? If there is a specific title, main text, or CTA, provide it exactly as you want it written.
  2. What is the exact name of your page, channel, account, or brand?
  3. Do you want to use your profile picture, logo, channel cover, or page image in the design? If yes, ask the user to upload it.
  4. Which platform is this design for (Facebook, Instagram, YouTube, Telegram, TikTok, or another platform)?
- Do not ask anything else unless a necessary piece of information is genuinely missing.
- If the user has already provided any of these details, do not ask for them again. Use the information already provided.
- If the user uploads a logo, banner, profile image, or reference image, analyze it and incorporate its visual identity appropriately rather than inventing a different brand identity.
- If the user does not have a logo or profile image, do not invent one. Keep the branding minimal or use the supplied page/channel/account name as subtle text when appropriate.
- After the user answers the questions, generate the image immediately without asking for another confirmation.
- Treat the user's answers as the source of truth for all text, branding, platform requirements, and visual preferences.
- Never insert example text, brand names, logos, page names, or content from this prompt into the final image unless the user explicitly provides or requests them.
- Never copy the exact content of a reference image. Extract its visual principles, composition logic, material treatment, lighting, hierarchy, and overall art direction while creating an original design for the user's content.

OVERALL ART DIRECTION:
A sophisticated black-and-gold mystery/puzzle design with a dramatic, premium, slightly mysterious atmosphere. Use a deep matte black textured background with subtle stone, charcoal and distressed-paper textures. The design should feel like a high-end intellectual puzzle brand, not a generic AI-generated poster.

COMPOSITION:

- Keep the visual hierarchy extremely clear.
- Place the main content in the center of the canvas.
- Leave balanced negative space around the main elements.
- Use a large irregular dark stone/slate panel in the center as the main text container.
- Above it, place a torn, rough-edged golden parchment/paper strip with a slightly distressed texture.
- Place a glowing vintage light bulb centered above the golden strip, symbolizing an idea or intelligence.
- Add several large metallic question marks around the composition, partially entering from the edges:
  - one near the upper-right corner,
  - one near the lower-left corner,
  - one near the lower-right area,
  - one subtle question mark on the left side.
- The question marks should look like heavy aged metallic objects with realistic reflections, scratches and cinematic lighting.
- Add a few tiny floating golden sparks/particles around the composition, but keep them subtle.
- Use depth, shadows and atmospheric glow to separate the layers.

COLOR PALETTE:

- Dominant: deep black / charcoal
- Secondary: warm metallic gold
- Text: ivory white
- Accent: amber/orange gold
- No bright blue, purple, green or unnecessary colors.
- Gold should be used selectively as an accent, not as the dominant background color.

TYPOGRAPHY:
Use bold, highly legible typography appropriate to the user's language and content, with a modern premium feel.
Create a clear hierarchy based on the user's supplied content:

1. Optional headline/title on the golden torn-paper strip, using the user's exact headline if provided.
2. Large central main content using the user's exact text, with selected important words, numbers, or concepts highlighted in gold when appropriate.
3. Optional bottom call-to-action using the user's exact CTA if provided.

Make the typography large, clean, correctly rendered, properly aligned and highly readable. Preserve the user's exact wording. Do not randomly change, misspell, translate, shorten, expand, or invent any words.

TEXT HIERARCHY:
The user's headline/title should be visually prominent but secondary to the main content when both are present.
The main user-provided content must be the strongest textual element.
Highlight important numbers and key words using warm gold when it improves readability and visual hierarchy.
If the content contains a question, conclusion, or key phrase, it may be visually emphasized in gold.

BRANDING:
Use the user's supplied page, channel, account, brand, or personal identity.
If a logo is provided, place it in a clean, visually appropriate location and preserve its recognizable identity without distorting it.
If a logo is not provided but the user supplied a brand/page/channel name, use that name subtly as a premium textual brand mark only when appropriate.
Keep branding secondary to the main content. Never invent a logo or brand name unless the user explicitly asks for one.

BOTTOM CTA:
If the user provides a CTA, create a small elegant rounded rectangular black panel with a thin warm-gold outline at the bottom. Add an appropriate minimal icon and the user's exact CTA text. Add a subtle directional element only when it improves the composition.
If no CTA is provided and one is not naturally required by the platform/content, do not invent one.

LIGHTING:
Cinematic studio lighting, realistic warm golden glow from the light bulb, subtle rim lighting on the metallic question marks, controlled highlights, deep shadows, realistic material reflections, volumetric light, high contrast.

MATERIALS:
Realistic distressed black stone, rough torn paper, aged metallic surfaces, brushed gold, subtle scratches and imperfections. Avoid plastic-looking materials.

STYLE:
Premium social media graphic, cinematic editorial design, luxury mystery poster, sophisticated Arabic typography, realistic 3D objects, dramatic lighting, high-end advertising art direction, extremely clean composition, sharp details, professional graphic design.

REFERENCE AND BRAND ADAPTATION:

- If the user provides a logo, profile picture, channel/page image, or other supplied reference, incorporate it naturally and preserve its recognizable identity without distorting it.
- Do not ask the user to define a new visual identity. The visual direction is already established by this prompt.
- If a reference image is supplied, use it only to understand the user's identity or the requested visual context; never copy its text or content.
- The final design must feel custom-made for the user's content while preserving the established art direction.

CONTENT ADAPTATION:

- Adapt the composition to the actual amount and type of user-provided text.
- If the content is short, use negative space intelligently instead of filling empty areas with random elements.
- If the content is long, prioritize readability and restructure the visual hierarchy without changing the user's wording.
- Select decorative elements that support the subject of the user's content. Do not force puzzle-specific objects such as question marks or a light bulb when the user's topic does not justify them.
- Preserve the premium black-and-gold visual language unless the user's brand identity or answers explicitly request another palette.

IMPORTANT:
The composition must remain uncluttered.
Do not add unnecessary icons, decorative objects, random symbols, excessive particles, excessive text, gradients or colorful elements.
The central riddle must remain immediately readable on a smartphone.
Maintain strong visual hierarchy and symmetry while keeping the torn paper and stone panels naturally irregular.

OUTPUT:
1:1 square format, ultra-high resolution, sharp details, professional social media post, optimized for mobile viewing.
Generate the final image immediately after collecting the user's answers. Do not ask for confirmation once all required information is available.
```

- تحديد النص الذي سيظهر في التصميم.
- تحديد اسم الصفحة أو القناة أو الحساب.
- دمج صورة الملف الشخصي أو الشعار عند توفيرها.
- تحليل الصور المرجعية المرفوعة.
- الحفاظ على هوية العلامة عند توفير مرجع.
- تكييف التصميم حسب المنصة.
- إنشاء تصميم مربع 1:1.
- استخدام أسلوب بصري داكن وفاخر.
- بناء تكوين سينمائي.
- استخدام الإضاءة الدرامية.
- استخدام خامات واقعية.
- تنظيم النصوص بصريًا.
- إبراز الكلمات والأرقام المهمة.
- الحفاظ على قابلية القراءة على الهاتف.
- تجنب ازدحام التصميم.
- عدم اختراع نصوص أو شعارات أو علامات تجارية.
- عدم نسخ محتوى الصور المرجعية.
- تحويل المبادئ البصرية للمرجع إلى تصميم أصلي.
- تكييف التكوين مع كمية النص.

- الحفاظ على التسلسل البصري الواضح.

## 📝 المعلومات التي يطلبها المساعد

يسأل المساعد فقط عن المعلومات الضرورية:

### 1. النص

ما النص الدقيق الذي تريد ظهوره في الصورة؟

ويشمل عند الحاجة:

- العنوان.
- النص الرئيسي.
- CTA.

> يجب الحفاظ على النص كما كتبه المستخدم دون ترجمة أو اختصار أو تغيير أو اختراع.

### 2. اسم الحساب

ما الاسم الدقيق لـ:

- الصفحة.
- القناة.
- الحساب.
- العلامة التجارية.

### 3. الهوية المرفوعة

هل تريد استخدام:

- صورة الملف الشخصي؟
- الشعار؟
- غلاف القناة؟
- صورة الصفحة؟

إذا كانت الإجابة نعم، يطلب المساعد رفع الصورة.

### 4. المنصة

تحديد المنصة المستهدفة:

- Facebook.
- Instagram.
- YouTube.
- Telegram.
- TikTok.
- أو منصة أخرى.

> [!IMPORTANT]
> لا يسأل المساعد عن الألوان أو الأسلوب أو التكوين أو الهوية البصرية؛ هذه العناصر محددة مسبقًا داخل البرومبت.

## 🎨 التوجه البصري

يعتمد التصميم على:

- خلفية سوداء عميقة.
- خامات حجرية وفحمية خفيفة.
- تفاصيل ورق متضرر عند الحاجة.
- ذهب معدني دافئ.
- أبيض عاجي للنص.
- لمسات Amber/Orange Gold.
- إضاءة سينمائية.
- ظلال عميقة.
- عمق بصري.
- خامات واقعية.
- تكوين فاخر.
- أجواء غامضة وراقية.

### الألوان

**الأساسي:**

أسود / فحمي.

**الثانوي:**

ذهبي معدني دافئ.

**النص:**

أبيض عاجي.

**اللمسات:**

ذهبي كهرماني.

> [!WARNING]
> لا يتم إدخال ألوان زاهية مثل الأزرق أو البنفسجي أو الأخضر دون سبب واضح.

---

## 🧩 التكوين

يعتمد التصميم على تسلسل بصري واضح.

العناصر الأساسية عند ملاءمتها للمحتوى:

- مساحة مركزية للمحتوى.
- لوحة حجرية داكنة غير منتظمة.
- شريط ورقي ذهبي ممزق.
- عناصر معدنية ثلاثية الأبعاد.
- إضاءة دافئة.
- ظلال عميقة.
- جزيئات ذهبية صغيرة عند الحاجة.
- مساحة سلبية متوازنة.

> [!NOTE]
> لا يتم إجبار جميع العناصر الزخرفية على الظهور. يجب أن تخدم الموضوع الفعلي للمستخدم.

---

## ✍️ التعامل مع النص

يتم إنشاء تسلسل واضح:

### العنوان

يمكن وضعه في شريط ذهبي عند وجود عنوان واضح.

### المحتوى الرئيسي

هو أقوى عنصر نصي في التصميم.

يجب:

- الحفاظ على النص حرفيًا.
- استخدام خط واضح.
- جعل النص مناسبًا للشاشة الصغيرة.
- إبراز الكلمات المهمة بالذهبي عند الحاجة.
- عدم إضافة كلمات غير موجودة في محتوى المستخدم.

### CTA

إذا قدم المستخدم CTA:

- يوضع في لوحة سوداء صغيرة.
- يستخدم إطارًا ذهبيًا رقيقًا.
- يكون واضحًا لكن ثانويًا.
- يمكن إضافة رمز بسيط مناسب.

إذا لم يقدم CTA:

> لا يخترع المساعد CTA من تلقاء نفسه.

---

## 🏷️ الهوية والعلامة التجارية

عند توفير شعار:

- يتم دمجه طبيعيًا.
- الحفاظ على هويته.
- عدم تشويهه.
- عدم تغيير تصميمه.
- وضعه بشكل ثانوي.

عند عدم توفير شعار:

- لا يتم اختراع شعار.
- يمكن استخدام اسم الصفحة أو القناة كنص بسيط عند الحاجة.

> [!IMPORTANT]
> العلامة التجارية يجب أن تبقى ثانوية مقارنة بالمحتوى الرئيسي.

---

## 🖼️ التعامل مع الصور المرجعية

عند رفع المستخدم:

- شعار.
- صورة شخصية.
- غلاف.
- صورة مرجعية.

يقوم المساعد بتحليل:

- الهوية.
- التكوين.
- الخامات.
- الإضاءة.
- المبادئ البصرية.

ثم يستخدمها لإنشاء تصميم أصلي.

### ممنوع

- نسخ النص الموجود في المرجع.
- نسخ محتوى المرجع.
- نسخ التصميم حرفيًا.
- اختراع هوية مختلفة للمستخدم.

---

## 📱 التكيف مع المنصة

يتم مراعاة طبيعة المنصة التي يحددها المستخدم.

ويجب أن يبقى التصميم:

- واضحًا على الهاتف.
- سريع الفهم بصريًا.
- متوازنًا.
- مناسبًا لطبيعة المحتوى.
- محافظًا على التسلسل البصري.

### المقاس الأساسي

**1:1 Square**

مناسب للمنشورات المربعة على منصات التواصل الاجتماعي.

---

## 🧠 التكيف مع المحتوى

### المحتوى القصير

يتم استخدام المساحة السلبية لصالح التصميم.

لا يتم ملء الفراغ بعناصر عشوائية.

### المحتوى الطويل

يتم:

- تنظيم النص.
- تحسين التسلسل.
- تقسيم المساحات.
- الحفاظ على جميع كلمات المستخدم.
- إعطاء الأولوية للقراءة.

> [!WARNING]
> لا يتم اختصار أو تغيير النص لمجرد جعله أسهل بصريًا.

---

## 💡 العناصر الزخرفية

يمكن استخدام عناصر مثل:

- علامات الاستفهام المعدنية.
- المصباح المتوهج.
- الشرارات الذهبية.
- الألواح الحجرية.
- الورق الممزق.
- العناصر ثلاثية الأبعاد.

لكن بشرط:

> **أن تكون مرتبطة بالمحتوى وتخدم الفكرة بدل أن تكون مجرد زخرفة.**

## 💡 الإضاءة

يعتمد التصميم على:

- إضاءة سينمائية.
- توهج ذهبي دافئ.
- Highlights مضبوطة.
- ظلال عميقة.
- Rim Lighting عند الحاجة.
- انعكاسات واقعية على المعادن.
- Volumetric Light بشكل خفيف.

---

## 🧱 الخامات

يجب أن تبدو الخامات واقعية، مثل:

- الحجر الأسود المتضرر.
- الورق القديم.
- المعدن المعتق.
- الذهب المصقول أو المصقول بالفرشاة.
- الخدوش البسيطة.
- العيوب الطبيعية.

وتجنب:

- البلاستيك.
- الأسطح الاصطناعية.
- اللمعان المفرط.
- الخامات غير الواقعية.

## 📊 المخرجات المتوقعة

بعد جمع المعلومات المطلوبة، يقوم المساعد بإنشاء:

1. تصميم اجتماعي فاخر.
2. تكوين مربع 1:1.
3. نص المستخدم بشكل صحيح.
4. هوية الحساب عند توفيرها.
5. تكوين مناسب للمنصة.
6. إضاءة سينمائية.
7. خامات واقعية.
8. تسلسل بصري واضح.
9. تصميم مناسب للمشاهدة على الهاتف.
10. صورة نهائية عالية الدقة.
